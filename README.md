# 班级照片管理文档

本仓库用于存放班级共享相册与校方提供照片的协作说明。文档仅供班级内部讨论和参考，不代表学校规定、法律意见或照片授权。

## 文档目录

- [班级共享相册协议（班级自治版）](班级共享相册协议-班级自治版.md)：说明班级共享相册的权限、传播、公开发布与隐私保护。
- [校方提供照片管理协议（班级协作版）](校级提供照片管理协议-班级协作版.md)：说明班级成员如何配合处理校方提供的照片。
- [index.html](index.html)：浏览上述文档的简易网页入口。

## 使用说明

- 以学校通知、说明或其他正式安排为准。
- 有关学校授权、校级平台或学校原件的事项，应由班主任或学校指定人员确认。
- 使用前请结合班级实际情况进行讨论，必要时及时反馈异议或疑问。
